# Claude Chat Interface

A beautiful, interactive chat interface powered by Claude AI, featuring concept highlighting and deep-dive capabilities.

## Features

- 🎨 Modern, responsive UI with smooth animations
- 💬 Real-time streaming responses from Claude
- 🔗 Interactive concept links with tooltips
- 📚 Deep-dive functionality for exploring topics in detail
- 🎯 Text selection menu for quick actions
- 📱 Split-view mode for simultaneous conversations
- ⚡ Built with React + Vite + Tailwind CSS

## Prerequisites

- Node.js 16+ and npm
- An Anthropic API key ([Get one here](https://console.anthropic.com/))

## Setup Instructions

### 1. Install Dependencies

```bash
npm install
```

### 2. Configure API Key

Create a `.env` file in the root directory:

```bash
cp .env.example .env
```

Edit `.env` and add your Anthropic API key:

```
VITE_ANTHROPIC_API_KEY=sk-ant-api03-...
```

> **Important:** Never commit your `.env` file to version control. It's already listed in `.gitignore`.

### 3. Run the Development Server

```bash
npm run dev
```

The app will start at `http://localhost:3000`

### 4. Build for Production

```bash
npm run build
```

The built files will be in the `dist/` directory.

## Deploy to Vercel

### Method 1: Using Vercel Dashboard (Recommended for Web)

1. **Push your code to GitHub** (already done if you followed setup)

2. **Go to [Vercel](https://vercel.com/)** and sign in with GitHub

3. **Click "Add New Project"**

4. **Import your repository**:
   - Select "JDerekLomas/homework" from your GitHub repos
   - Click "Import"

5. **Configure the project**:
   - Framework Preset: Vite (should auto-detect)
   - Root Directory: `./` (leave as is)
   - Build Command: `npm run build` (auto-filled)
   - Output Directory: `dist` (auto-filled)

6. **Add Environment Variable**:
   - Click "Environment Variables"
   - Name: `VITE_ANTHROPIC_API_KEY`
   - Value: `sk-ant-api03-your-api-key`
   - Click "Add"

7. **Click "Deploy"**

Your app will be live in ~2 minutes at a URL like: `your-app.vercel.app`

## How to Get an Anthropic API Key

1. Go to [https://console.anthropic.com/](https://console.anthropic.com/)
2. Sign up or log in to your account
3. Navigate to API Keys section
4. Click "Create Key"
5. Copy the key (starts with `sk-ant-api03-...`)
6. Paste it into your `.env` file

## Usage

### Basic Chat

1. Type your message in the input box
2. Press Enter or click Send
3. Claude will respond with streaming text
4. Key concepts will be highlighted as interactive links

### Concept Exploration

- **Hover** over highlighted concepts to see quick definitions
- **Click "Learn more"** in the tooltip to open a deep-dive panel
- **Select text** in any message to see additional options

### Deep Dive Mode

- Click "Learn more" on any concept to open a split-view
- Ask follow-up questions in the deep-dive panel
- Close with the X button to return to main chat

## Key Differences from Gemini Version

This version has been modified to use the Claude API instead of Google's Gemini:

1. **API Endpoint**: `https://api.anthropic.com/v1/messages`
2. **Authentication**: Uses `x-api-key` header
3. **Streaming Format**: Server-Sent Events (SSE) with `content_block_delta` events
4. **Model**: Claude Sonnet 4 (`claude-sonnet-4-20250514`)
5. **Message Role**: Uses `assistant` instead of `model`

## Customization

### Change the Model

Edit `src/App.jsx` and modify the model parameter:

```javascript
model: 'claude-sonnet-4-20250514', // or claude-3-5-sonnet-20241022, etc.
```

### Adjust System Prompt

Modify the `SYSTEM_PROMPT` constant in `src/App.jsx` to change Claude's behavior.

### Styling

Colors and styling can be customized in:
- `tailwind.config.js` - Theme configuration
- `src/App.jsx` - Component-level styles

## Troubleshooting

### "Please set your VITE_ANTHROPIC_API_KEY" Error

- Make sure you created a `.env` file (not `.env.example`)
- Verify the API key starts with `sk-ant-api03-`
- Restart the dev server after adding the key

### API Errors

- Check your API key is valid
- Verify you have credits in your Anthropic account
- Check the browser console for detailed error messages

### Build Errors

- Delete `node_modules` and run `npm install` again
- Clear the cache: `rm -rf node_modules/.vite`
